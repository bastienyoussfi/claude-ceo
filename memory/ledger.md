# Ledger

Append-only transaction log. Every euro in or out gets a line the same day, with a source. Never invent a number — write "UNKNOWN — ask Operator" instead. Running totals are not kept here; the CEO recomputes them in each daily standup.

P&L is tracked in two modes:
- **Cash mode:** revenue − cash expenses (hosting, domain, tools)
- **Hard mode:** revenue − cash expenses − estimated AI/API costs
