# Content pipeline

The human-in-the-loop, made physical:

1. The CEO (or the growth agent) drafts into `queue/` — one file per draft: `YYYY-MM-DD-platform-slug.md`, with target platform and audience at the top.
2. The Operator publishes it, then moves the file to `posted/`, appending the live link and, later, its stats.
3. The next session's BOOT sees exactly what went live and how it performed. Nothing in `queue/` is public yet; everything in `posted/` is.
